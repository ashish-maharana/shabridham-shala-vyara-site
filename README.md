# Shabridham Shala Website

Static Next.js (App Router) + Tailwind CSS website for:
- Shabridham Shala
- Vyara, Tapi, Gujarat, India

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React icons
- Fully static export (`output: "export"`)

## Run Locally
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```

## Notes
- Learnify-style school website concept with lavender canvas, rounded panels, coral CTAs, yellow/purple cards, and placeholder-only assets.
- Public school facts are conservative and editable until official confirmation.
- YouTube channel is included as a media/social link only.
